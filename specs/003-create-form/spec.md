# Ітерація 003: Форма створення

## Мета ітерації

Дати змогу додати новий проєкт та завдання через форму, яка валідує дані на
клієнті перед відправкою.

## Що вже є

Список проєктів та завдань із пагінацією (ітерації 001-002).

## Що додаємо

- Кнопку "Додати проєкт" в шапці сторінки.
- Модальне вікно з формою: "Назва"(name), "Опис"(description).
- Клієнтську валідацію (дзеркалить обмеження бекенду):
  - name: обов'язкове, <= 200 символів.
  - description: textarea не обов'язково.
  - Форма не відправляється, якщо є помилки - під кожним невалідним
    полем показується текст помилки.
- Після успішного POST /projects/ форма закривається, список
  оновлюється без перезавантаження сторінки.
- Кнопку "Додати завдання" показується після розкривання проєкта.
- Модальне вікно з формою: "Назва"(title), "Опис"(description), "Приоритет"(priority), "Дата завершення"(due_date).
- Клієнтську валідацію (дзеркалить обмеження бекенду):
  - title: обов'язкове, <= 150 символів.
  - description: textarea не обов'язково.
  - priority: select з значенями low, medium, high. medium - за замовчуваням
  - due_date: date не обов'язково.
  - Форма не відправляється, якщо є помилки - під кожним невалідним
    полем показується текст помилки.
- Після успішного POST /projects/{id}/tasks форма закривається, список
  оновлюється без перезавантаження сторінки.

## Явно поза межами цієї ітерації

- Редагування наявного проєкту чи завдання - НЕ додавати (тільки створення).
- Видалення - НЕ додавати.
- Детальний показ помилки - досить стандартного
  alert() та виводу в консоль, деталізуємо в ітерації 005.

## Критерії приймання

- [ ] Кнопка "Додати проєкт" та "Додати завдання" відкриває порожню форму.
- [ ] Спроба відправити форму з порожнім name, title, due_date сьогоднішню або меншою показує помилку і не
      відправляє запит.
- [ ] Успішне створення додає проєкт та завдання в проєкт в список без перезавантаження
      сторінки.
