# Ітерація 001: Базовий список проєктів

## Мета ітерації

Показати на сторінці список усіх проєктів, отриманий з бекенду. Без
фільтрів, без форм, без редагування - тільки читання й відображення.

## Що вже є

Нічого. Це перша ітерація, index.html/style.css/app.js порожні або
не існують.

## Що додаємо

- Шапку сторінки з назвою "Tasks Manager".
- Акордеон проєктів: name, description і стрілочка, яка показує, що можна розкрити.
- Після натискання стрілочки показуються завдання(tasks) цього проєкту: title, is_done(True ("Виконано") / False ("В процесі"))
- Завантаження списку через GET /projects/ (без параметрів) одразу
  після завантаження сторінки.
- Після натискання на title завдання через GET /tasks/{id} в модальному вікні буде відопражатися завдання(task): title, description, is_done, due_date, priority.
- Стан завантаження ("Завантаження..."), стан порожнього списку
  ("Проєктів поки немає") і стан порожнього списку завданнь ("Завдання не додані").
- В app.js додай коментарії

## Явно поза межами цієї ітерації

- Кнопки "Додати", "Редагувати", "Видалити" - НЕ додавати.
- Фільтри і пагінація - НЕ додавати.
- Окремий banner для помилок API - НЕ потрібен (досить
  console.error за наявності мережевої помилки).

## Критерії приймання

- [ ] При відкритті сторінки виконується GET /projects/ і список
      відображається.
- [ ] Кожен проєкт показує всі поля, перелічені в розділі
      "Що додаємо".
- [ ] Кожне завдання показує всі поля, перелічені в розділі "Що додаємо".
- [ ] Порожній список бекенду показує повідомлення, а не порожню
      сторінку.
